# تقرير التحقق من مكتبة البرومبتات

يُولَّد هذا التقرير آلياً بالأمر `npm run catalog` من الملف `sinara-handoff/catalog/sinara-prompts.json` (البصمة `789954c89d00`). النتيجة نفسها تتكرر مع المدخل نفسه.

## المجاميع

- المواقف المستقلة (الحالات الأم): 120
- الصيغ المستوردة: 2,400
- الصيغ القابلة للاستعمال (غير المحجوزة): 2,392
- بحسب الحالة التحريرية: مستوردة دون فحص 0 · مفحوصة آلياً 2,392 · مراجَعة بشرياً 0 · محجوزة 8
- صيغ الواجهة النموذجية (بجواب تعليمي مكتوب): 12

الصيغ مولّدة تعليمياً بمدخلات خيالية. ليست 2,400 حالة مستقلة ولا أجوبة خبراء مراجَعة. كل صيغة مربوطة بحالتها الأم وتُعدّ الحالة مرة واحدة.

## الفحوص الآلية (ناجحة)

- الحقول العشرة موجودة وغير فارغة في كل سجل.
- المعرّفات فريدة، وكل صيغة مرتبطة بحالة أم موجودة، وحقول الحالة متطابقة بين صيغها.
- لا تكرار حرفياً بعد إزالة التشكيل وتوحيد الهمزات والتاء المربوطة والأرقام وعلامات الترقيم.
- كل مجموعة مربوطة بمجال في سِينارة، والروابط إلى التخصصات الفرعية موجودة.
- لا يُعرض أي سجل لفئات ٤–٦ و٧–٩ و١٠–١٢. حالات المرافق تُعرض للبالغين فقط.
