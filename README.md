# سِينارة | منصة عراقية لتعلّم مهارات التعامل مع الذكاء الاصطناعي

> «شنو ببالك؟ خلّيه سؤال»

سِينارة اسم المنصة، و**فَطين** اسم المرشد الآلي، و**«فنّ السؤال»** اسم المسار التعليمي الأول. صيغ الاسم من سين السؤال والإنارة: كلما أضاف المتعلّم تفصيلاً مفيداً إلى سؤاله أضاء جزء من علامة الاستفهام أمامه.

إعداد: البروفيسور عماد محمد فرحان.

---

## ماذا في هذا المستودع؟

- **موقع وتطبيق ويب تقدّمي (PWA)** بالعربية من اليمين إلى اليسار، يعمل دون إنترنت بعد أول تحميل ناجح.
- **مشروعا أندرويد وآي أو إس** (Capacitor) يستعملان المحتوى والواجهة نفسيهما.
- **خادم اختياري للمحادثة المباشرة** في المجلد `server/`، منفصل عن الموقع، ولا يعمل إلا بعد تهيئته.
- **المحتوى التعليمي كله** في ملفات `src/content/` مستقلاً عن الشاشات.

المسارات: ست فئات عمرية، وأربع ألعاب لعمر ٤–٦، وثمانية عشر موضوعاً مدرسياً لعمر ٧–١٢، ومشروع الأهوار لعمر ١٣–١٧، واثنا عشر مجالاً مهنياً فيها سبعة وأربعون تخصصاً فرعياً، ومولّد طلبات بعشر خدمات، ورحلتان كاملتان: «قصة الطفل والمرافق» و«ارسم لي خريطة بيت».

## التشغيل على حاسوبك

يحتاج Node.js 22 أو أحدث.

```bash
npm ci
npm run dev          # يفتح نسخة التطوير على http://localhost:5173
npm run validate     # يفحص المحتوى: المعرّفات، والروابط، ومفاتيح الأسئلة، والأسلوب العربي
npm test             # اختبارات المنطق واختبارات الخادم بمزوّد محاكاة
npm run build        # نسخة النشر في المجلد dist
```

اختبارات القبول في المتصفح:

```bash
npx playwright install chromium
npx playwright test
```

## النشر على GitHub Pages

1. أنشئ مستودعاً فارغاً باسم `sinara` في حسابك `imadmfas`.
2. ادفع هذا الفرع ثم ادمجه في `main`:
   ```bash
   git remote add origin https://github.com/imadmfas/sinara.git
   git push -u origin feature/sinara-fann-al-sual
   ```
   ثم افتح طلب الدمج على GitHub وادمجه، أو ادفع الفرع إلى `main` مباشرة.
3. من إعدادات المستودع: **Settings ← Pages ← Source**، واختر **GitHub Actions**.
4. يبني سير العمل `.github/workflows/pages.yml` الموقع ويختبره وينشره تلقائياً عند كل دفع إلى `main`. يصبح الرابط:
   `https://imadmfas.github.io/sinara/`

يضبط سير العمل المسار الفرعي تلقائياً باسم المستودع، وتعمل الروابط الداخلية وتحديث الصفحة لأن التنقل يعتمد على علامة `#`.

## الخادم الاختياري للمحادثة المباشرة

«مرشد الدرس» يعمل في كل الأعمار دون إنترنت ودون أي خادم. أما «المحادثة الذكية المباشرة» فللبالغين فقط، ولا تظهر إلا بعد هذه الخطوات:

```bash
cd server
npx wrangler login                          # حساب Cloudflare مجاني
npx wrangler secret put ANTHROPIC_API_KEY   # مفتاح مزوّد النموذج
npx wrangler secret put SESSION_SECRET      # نص عشوائي طويل
npx wrangler secret put ADULT_ACCESS_CODE   # رمز تعطيه للبالغين فقط
npx wrangler deploy
```

- عدّل `ALLOWED_ORIGIN` في `server/wrangler.toml` إذا تغيّر رابط الموقع.
- أضف رابط الخادم في المستودع: **Settings ← Secrets and variables ← Actions ← Variables** باسم `LIVE_COACH_URL`، ثم أعد النشر.
- يتحقق الخادم من رمز البالغ ويمنح جلسة مؤقتة موقّعة (٣٠ دقيقة). تغيير الفئة العمرية داخل التطبيق لا يفتح المحادثة. لا تُحفظ المحادثات، والمفاتيح تبقى في الخادم.

## تطبيق أندرويد

```bash
npm run cap:sync                      # يبني نسخة التطبيق وينسخها إلى android/ و ios/
cd android && ./gradlew assembleDebug # ملف التجربة: android/app/build/outputs/apk/debug/app-debug.apk
```

يمكنك أيضاً تشغيل سير العمل **Android debug APK** من تبويب Actions وتنزيل الملف.

**للنشر في متجر Google Play** تحتاج مفتاح توقيع خاصاً بك (لا يوجد في المستودع ولا يجوز رفعه إليه):

```bash
keytool -genkey -v -keystore sinara-release.keystore -alias sinara -keyalg RSA -keysize 2048 -validity 10000
```

ثم افتح `android/` في Android Studio واختر **Build ← Generate Signed Bundle / APK**، واحفظ المفتاح وكلمة سره في مكان آمن؛ فقدانه يمنع تحديث التطبيق لاحقاً.

## تطبيق آي أو إس

يحتاج جهاز Mac عليه Xcode وCocoaPods، وحساب Apple Developer للتوقيع.

```bash
npm run cap:sync
cd ios/App && pod install
open App.xcworkspace
```

في Xcode: اختر الهدف **App** ← **Signing & Capabilities** ← فريقك (Team)، وغيّر معرّف الحزمة `iq.sinara.app` إن لزم، ثم **Product ← Archive** للرفع إلى App Store Connect. يوجد سير عمل **iOS simulator build** يبني نسخة غير موقّعة على خوادم macOS في GitHub للتأكد من سلامة المشروع.

## تعديل المحتوى دون لمس الشاشات

كل النصوص العربية في `src/content/`:

| الملف | ما فيه |
|---|---|
| `brand.ts` | اسم المنصة والشعار واسم المرشد وترحيب الأطفال |
| `branches.ts` | المجالات المهنية والتخصصات وطلباتها |
| `fieldQuizzes.ts` | أسئلة «اختبر نفسك» والأجوبة التعليمية الخاطئة |
| `followups.ts` | سيناريوهات «شنو نسأل بعدها؟» |
| `preschool.ts` | قصص الأطفال وألعابهم |
| `school.ts` | موضوعات ٧–١٢ |
| `house.ts` | رحلة خريطة البيت وجدول المساحات |
| `services.ts` | خدمات مولّد الطلبات وخاناتها |
| `guide.ts` | دليل البداية |
| `audio.ts` | ربط النصوص بتسجيلات صوتية عربية |

**لإضافة تخصص جديد:** أضف عنصراً إلى مصفوفة `branches` في المجال المناسب داخل `branches.ts`، فيه: `id` فريد، والاسم، والطلب الغامض، والطلب المحسّن، والعبارات الملوّنة (يجب أن تكون موجودة حرفياً في الطلب المحسّن)، والتعليل، والشرح المبسّط. ثم شغّل `npm run validate`. يظهر التخصص تلقائياً في البحث والقوائم والمولّد ومرشد الدرس.

يرفض الفحص البناء إذا تكرر معرّف، أو نقص محتوى تخصص، أو انكسر رابط، أو كان لسؤال أكثر من جواب صحيح، أو لم يساوِ مجموع مساحات البيت ٢٠٠ متر مربع، أو ظهرت في النصوص العربية العبارات والأساليب التي طلبتَ تجنّبها.

## تغيير الرسوم والأصوات

- الرسوم كلها أصلية ومرسومة بالشيفرة في `src/components/Art.tsx` (فَطين، علامة الاستفهام، الحيوانات والأماكن). عدّل الأشكال والألوان هناك.
- الألوان والخطوط في `src/styles/app.css`. الخط IBM Plex Sans Arabic مضمّن محلياً برخصة SIL المفتوحة.
- أيقونة التطبيق في `public/icon.svg`.
- المؤثرات الصوتية تُولَّد في الجهاز (`src/lib/sound.ts`) وتبدأ صامتة.
- **التسجيلات العربية:** ضع الملف في `public/audio/` واربطه بالنص في `src/content/audio.ts`. إذا لم يوجد تسجيل استُعمل صوت الجهاز العربي إن وُجد، وإلا ظهرت عبارة «يقرأ المرافق النص بصوته» بدل زر لا يعمل.

نحفظ على الجهاز فقط: الفئة العمرية، والتقدّم لكل فئة منفصلاً، والإعدادات. لا نطلب اسماً أو مدرسة أو صورة أو عنواناً. ما يُكتب في الحقول لا يُحفظ إلا إذا ضغط بالغ «احفظ المسودة»، ولا يُرسل شيء إلى أي نموذج تلقائياً.
